# Beyond the Section Plane

Code for the paper:

**Beyond the section plane: Robust 3D reconstruction of multiplex immunofluorescence exposes limitations of 2D spatial cell statistics**
Junming Ma, Olle Edgren Schüllerqvist, Hui Yu, Carina Strell, Patrick Micke, Joakim Lindblad, Artur Mezheyeuski, Nataša Sladoje

Preprint: [arXiv:2611.28905](https://arxiv.org/abs/2611.28905)

## Status

The paper has been submitted to the IEEE International Symposium on Biomedical Imaging (ISBI 2027). The code will be released in this repository once the review process is complete.
